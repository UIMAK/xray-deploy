# xray-deploy

## 📥 安装

```bash
bash <(wget -qO- https://raw.githubusercontent.com/UIMAK/xray-deploy/main/install.sh || curl -fsSL https://raw.githubusercontent.com/UIMAK/xray-deploy/main/install.sh)
```

**快捷命令:`xd`**(安装后输入 `xd` 唤出主菜单)

安装器会自动准备 Python 3；分享链接解析使用随项目安装的 Python 标准库脚本，配置、服务与事务仍由 Shell 管理。
